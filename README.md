# Cochin Energy × Ennyescee

An interactive prototype connecting Cochin Energy System's industrial dehydration technology with Ennyescee Food Factory's consumer products.

## Development

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm run preview
```

The Vite build uses relative asset paths for GitHub project Pages. Source-content decisions and conflicts are documented in `docs/design-brief.md`.
